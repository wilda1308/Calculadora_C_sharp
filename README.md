# Calculadora C#
Calculadora totalmente funcional donde existen botones de sumar, restar, numeros del 0 al 9, borrar, eliminar todo entre otros, tiene un diseño simple y cuenta con toda la lógica que debe tener cada botón al darle clic. Este pequeño proyecto esta realizado en el lenguaje de C# con la herramienta de Visual Studio y utilizando formularios o ventanas.
