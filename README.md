# 📱Calculadora Desktop

¡Bienvenido al proyecto **Calculadora**! Este proyecto es una aplicación de escritorio interactiva diseñada con una interfaz gráfica intuitiva y limpia, desarrollada utilizando **C#** como lenguaje principal y estructurada dentro del entorno de **Visual Studio**.

---

## Características

* **Operaciones Básicas:** Soporte completo para suma, resta, multiplicación y división.
* **Manejo de Excepciones:** Control de errores lógico, incluyendo la prevención de divisiones por cero.
* **Interfaz de Usuario (UI) Moderna:** Componentes gráficos organizados para una experiencia de usuario cómoda y ágil.

---

## Tecnologías y Herramientas

* **Lenguaje de Programación:** C#
* **Entorno de Desarrollo (IDE):** Visual Studio
* **Librería Gráfica:** Windows Forms
* **Distribución:** GitHub

---

## Estructura del Proyecto

El código fuente del proyecto se organiza bajo el siguiente estándar limpio de directorios:

```Estructura del proyecto
├── Calculadora/
│   ├── Calculadora/                      # Proyecto construido en VisualStudio
│   │   ├── bin/                          # Compilación de formularios y lógica.
│   │   ├── obj/                          # Objetos utilizados en los form.
│   │   ├── propierties                   # Propiedades o configuración del proyecto.
│   │   ├── App.config                    # Propiedades o configuración del proyecto.
│   │   ├── Calculadora.scproj            # Constructor del proyecto C#.
│   │   ├── Form 1.cs                     # Código en C# del proyecto, lógica de los eventos, aplicación de excepciones.
│   │   ├── Form 1.Designer.cs            # Diseñador intuitivo de Windows Forms.
│   │   ├── Form 1.resx                   # XML que almacena datos del proyecto en formato de clave-valor.
│   │   └── Program.cs                    # Archivo principal y punto de entrada de la aplicación
│   └── Calculadora.sln                   # Solución para abrir en Visual
├── InterfazGrafica.png                   # Imagen de visualización de la interfaz
├── LICENSE                               # Licencia actual del proyecto
└── README.md                             # Documentación del proyecto
```
## Instalación y Ejecución

Para Usuarios (Ejecución Rápida)
Si solo quieres probar el funcionamiento de la calculadora en tu entorno Windows:

Descarga el archivo `Calculadora.sln` del repositorio.

Haz doble clic sobre él para iniciar el programa en Visual Studio.

>[!Note]
>Nota: Se requiere tener instalado el Entorno de desarrollo IDE Visual Studio 2022 en el equipo.
